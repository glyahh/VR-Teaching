# 自由探索样课与三维共用代码

- 本目录维护独立样课入口、Three.js 场景、交互和运行依赖。正式课件与独立样课共用 `exploration-stage.js` 和 `exploration-assets.mjs`。
- 运行素材放在 [assets](../assets/AGENTS.md)，Blender 和贴图制作代码放在 [media-source/exploration](../media-source/exploration/)。
- 从仓库根目录运行 `npm --prefix "课堂演示/自由探索实验" run build` 生成样课。按[复跑说明](../../展示材料/遵义自由探索原型/对照与复跑.md) 验证样课和受影响的正式入口。
