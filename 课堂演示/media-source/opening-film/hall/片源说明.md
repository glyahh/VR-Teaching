# 遵义会前情境入场镜头

[剪辑片源](./hall.mp4)是 1280 × 720、24 fps 的无声 H.264。片头剪辑以 72.25 秒和 76.65 秒为切点，四舍五入到第 1734 和 1840 帧。从全片 0 起数，本片源覆盖第 1728 至 1845 帧，共 118 帧。前后各 6 帧留给现有 12 帧叠化，导入时从帧零起取用。场景已在渲染中完成调色。

这段沿用课程材料厅的空间比例，表现进门看见书桌和提灯的会前情境。原片地点卡交代本段的历史节点。会议在柏辉章宅邸二楼东侧小客厅举行，下一镜用多人围桌的既有短片交代议事场面。

| 片源帧，从 1 起数 | 画面 |
| --- | --- |
| 1–26 | 沿乌江出镜的冷灰色进入庭院。檐下两盏灯照见瓦口、柱脚和潮湿石板，门内看得见桌灯。 |
| 27–74 | 向门槛靠近。木格门随转轴松开一小段，可以辨认铁合页、铜环、裙板和青石门枕。 |

| 97–118 | 相机靠近桌边后放缓。玻璃罩透出独立火苗，暖光照着桌板和纸件。冷窗保留在桌灯后方，接二楼会议镜头。 |

## 模型与材质

- 从课程的 hall-model.glb 保留庭院尺度、石板网格、旧木地板、邻屋、木窗和既有屋面。补出近檐陶瓦的圆弧端面，灰泥和砖基使用独立的粗糙与凹凸表面，调节石板和木地板局部反光。
- 原模型混合网格只修剪本镜拆换的局部。重建门套、滴水额、带实际轴心的铁合页、格扇、下部板芯、铜门环、木门槛和青石踏步。青灰砖窄边贴墙咬合，去掉门匾和室内教学陈列。
- 两盏外灯独立建模，木框、纸片、吊环与下穗随挂点轻摆，投在墙上的光同步小幅变化。门轴从约 65° 逐渐开到 78°。镜头以略低于人眼的高度平滑通过门洞。
- 从「会前的桌边」工程本地追加旧木桌、木椅、纸件、茶碗和薄壁玻璃提灯。桌灯用原火苗几何和独立暖光，按固定时间函数轻晃。薄壁灯罩改用透明与菲涅耳反射，保留罩边和金属高光。两面木窗后留出真实空间，能看见对面檐口和窗光。室内冷光从窗扇方向进入，桌面和木地板分别接住冷暖反光。

## 离线重建和照相机对照

在仓库根运行。Blender 4.5.4 和 FFmpeg 需已安装。运行所需 GLB、贴图和 Blender 工程已在仓库内。

```powershell
$blender = '.march-build/blender-4.5.4-windows-x64/blender.exe'
$scene = '课堂演示/media-source/opening-film/hall/render.py'
$out = '.march-build/片头模型制作/hall/final'
& $blender -b --factory-startup --disable-autoexec --python-exit-code 1 -t 12 --python $scene -- --output $out --blend "$out/hall.blend"
python -B '课堂演示/media-source/opening-film/hall/encode.py' $out '课堂演示/media-source/opening-film/hall/hall.mp4'
```

render.py 生成逐帧 PNG，可加 --stills 1 50 78 118 验收关键帧。默认用 Cycles CPU 和降噪；可用 --engine eevee --samples 8 --scale 70 快速核对静帧位置。薄壁灯罩的内外表面在 Cycles 中有更稳定的轮廓，整段使用同一渲染设置。

机位对照用 --reference 7 31。旧帧从 record-opening-3d.py 的原始材料厅录制取，帧序号从零起。旧轨迹的眼高为 1.57 米，使用 (x, -z, y) 从 WebGL 转 Blender。俯仰、偏航、垂直视角 61° 和对应帧缩放一并转入固定镜头。比较柱脚、檐线和窗框时保留构图，旧门内的教学墙和台面由新布局自然替代。
