# 片头人物的身体和服装

用于于都抬板、于都夜渡与湘江涉水。制作时保留可连续变形的人体、完整手腕、手掌及五指，使用 MakeHuman 共用的游戏骨架。服装、鞋、发和眼睛按同一副身体试穿，再导出为单个 GLB。原课堂活动仍从自己的 assets 目录加载。运行课件只需要剪辑后的 MP4。

| 部位 | 来源和处理 |
| --- | --- |
| 人体与手 | MPFB 2.0.18 的 MakeHuman 基础网格。去掉建模辅助面后保留 13,380 个体表顶点；上游衣裤及鞋的覆盖区使用独立透明材质，可以在 Blender 中单独检查完整解剖面。掌根、腕骨、拇指及其余四指均保留原始蒙皮。 |
| 脸、眼和头发 | 原始两套亚洲男性皮肤，保留颈与腕的 UV。另用 `eyes/high-poly`、`eyes/materials/brown_eye.png`、`eyebrows/eyebrow007` 和 `hair/short01`。透明虹膜外层、眼白、眉毛和发缘分别使用实际的表面或透明贴图。下颌与面颊采用 MPFB 自带的下巴宽度、突出度和双侧颊骨、颊量形态目标。 |
| 上衣与长裤 | `clothes/male_casualsuit03` 的上衣、裤装按原裁片分离和蒙皮。上衣放长下摆，长裤增加腿部余量，保留膝处褶面。AO、原纹理上的扣眼和 Poly Haven 粗麻布纹组成可染色的灰度底纹，保留原裁片褶皱法线。 |
| 布鞋与帽 | 鞋使用 `clothes/shoes04` 的鞋楦，按实网格鞋底定位，重调为旧布色。帽沿用项目于都人物的布帽。不同角色的背负和动作在各镜头内设置。 |

## 从原资产复建

解压系统包，保留上表的相对目录。另取两张原皮肤（`skins/young_asian_male/young_lightskinned_male_diffuse3.png` 和 `skins/middleage_asian_male/middleage_lightskinned_male_diffuse2.png`）。使用安装了 MPFB 2.0.18 的 Blender 4.5.4。以下从仓库根目录运行，临时贴图和重导出的模型写入指定目录。

```powershell
$src = '课堂演示/media-source/opening-film/cast/performance'
$tmp = (New-Item -ItemType Directory -Force '.march-build/人物重建').FullName
python -B "$src/prepare-textures.py" "$pack" "$linen_diff_1k" "$tmp"
blender -b --disable-autoexec --python-exit-code 1 -P "$src/build-performer.py" -- "$pack" "$tmp" "$((Resolve-Path '课堂演示').Path)" "$tmp/performer-final.glb" --targets "$mpfb_targets"
```

`$pack` 是解压后的系统包根目录，`$linen_diff_1k` 是 Rough Linen 的 1K 颜色图，`$mpfb_targets` 是 MPFB 的 `data/targets` 目录。场景会另读同目录的 `skin-young.jpg` 和 `skin-middle.jpg` 为不同人物着色。
