# 长征课片头分镜及素材

放映入口衔接总览地形原图（`terrain.jpg`），收尾画面回到于都集结原图（`yudu-assembly.jpg`），再由教师点击「进入课堂」进入第一课页。片头按纪录片结构铺陈 1934 年秋至 1935 年 1 月的历史背景与四站因果：第五次反“围剿”受挫、于都夜渡、血战湘江、黎平改向、强渡乌江、遵义会议召开与全线四站时空回望，最后破晓转折回到于都起点。

## 重剪与核对

外部素材缓存放在 `.march-build/opening-sources/`，旁白分句缓存放在 `.march-build/opening-sources/voice-v2/`（对应文本稿 `课堂演示/media-source/opening-narration.tsv`）。缓存就绪后在仓库根目录执行：

```powershell
python -B "课堂演示/media-source/make-opening.py"
```

如需修改 `opening-narration.tsv` 并重合成男声旁白，加 `--synthesize` 参数。重剪依赖 Python（Pillow、NumPy）、系统微软雅黑/宋体字体以及 FFmpeg/FFprobe。正式课件打包时只内嵌 `课堂演示/assets/opening.mp4`，离线运行无需片源缓存。

正式课件重建后，用 `python -B "Test/verify-dual.py" --check-join opening terrain yudu-assembly` 核对 Edge 实际解码首尾帧误差，再从地图页点击「开始授课」播放并检查双屏同步、暂停续播与进入课堂衔接。
