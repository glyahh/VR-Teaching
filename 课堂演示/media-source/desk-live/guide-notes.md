# 从黎平到遵义

[90 秒导览成片](../../assets/desk-guide.mp4)用已审桌边主视图开场。旁白从“中央红军为什么会来到遵义”说起，沿黎平、猴场、乌江回到遵义会议桌。[片头片尾原图](../../../展示材料/遵义会议室精修场景/会前的桌边.png)

## 本机复跑

从仓库根目录运行。需要 Windows 简体中文桌面 SAPI 语音、Python 3.11 或更高版本、Pillow、NumPy、带 libx264 和 libass 的 FFmpeg、ffprobe，以及项目使用的 Blender 4.5.4。脚本优先选用 Microsoft Huihui Desktop。所有中间文件存入 `.march-build/desk-live/guide/`。

```powershell
python -B '课堂演示/media-source/desk-live/make_guide.py' build
python -B '课堂演示/media-source/desk-live/make_guide.py' verify
```

只有翻页素材还在渲染时，可先运行 `prepare`，生成侧机位、旁白、字幕和剪辑底片。正式合成从 [desk-action.mp4](../../assets/desk-action.mp4) 逐帧接入翻页。脚本在候选文件通过验证后写入成片。

[旁白与字幕表](guide-narration.tsv)的“入点”是秒数，带加号的数字是与上一句尾音之间的停顿。字幕默认也是朗读文本，日期单列汉字读法。脚本按 SAPI 的实际发声长度生成字幕时间，并把字幕烧录进画面。[构建脚本](make_guide.py) · [侧机位渲染脚本](guide-detail.py)

本版首句在 1.292 秒起声，末句在 87.083 秒收声，末条字幕于 87.167 秒撤下。开头 31 帧、结尾 68 帧均为无字、无旁白的已审主视图。首帧与末帧相对互动封面的水平、垂直配准偏移均为 0 像素。

验证结果在 `.march-build/desk-live/guide/verification.json`，含文件指纹、帧数、时长、关键帧间隔、净画面与原图误差、翻页逐帧对照、各句音频偏移及字幕边界检查。22 条字幕的起止各检查相邻两帧，共 88 帧。逐句实际入点与出点在同目录 `cues.json`（24 fps 帧号）和 `guide.ass`（字幕时码）。
