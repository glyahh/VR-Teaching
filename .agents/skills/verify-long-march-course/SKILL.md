# 验收《从于都到遵义》

从仓库根目录读 `AGENTS.md`、`两门课视觉与动效规范.md`，以及 `新一轮访谈信息/长征沉浸式VR党课落地方案.md` 的冻结版最高执行标准。记录本轮要解决的问题、实际入口、对照版本和涉及的画面。用 `git status --short` 识别原有工作，用 `Test/verify-lesson-scope.mjs` 检查当前声明的范围。

## 启动和诊断

只读核对时使用已生成的 `课堂演示/从于都到遵义-课堂演示.html`。实施获准后运行 `node "课堂演示/build.mjs"`，核对正式课件与成果预览的校验值。用安装了 Playwright、Pillow 和 Microsoft Edge 的 Python 环境运行 `python -B "Test/course_cli.py" doctor`。报告会列出成品校验值和浏览器版本，并截图证明地图上已显示「开始授课」。可在命令前部用 `--html` 指定对照版。

CLI 为每次运行复制一份 HTML 到空目录，用新的断网 Edge 上下文打开。`--viewport 1366x768` 指定单屏窗口尺寸。并行核验时分别指定 `--output`，以便定位各自的证据。

## 五项验收

| 标准 | 怎么证明 |
| --- | --- |
| 场景接得上 | 为每次过场记录出场、承接的物件或动作、入场。按正常速度连看。短片用实际解码首尾帧对照课页，核对构图、焦点、裁切、光线和动作位置。 |
| 动手有结果 | 逐项实做，记下操作对象、出现的画面变化和能据此说明的处境、选择或后果。把结果停下来比较，再走一次反向或重试。 |
| 物件经得起近看 | 正面、斜侧和近景都操作一遍。取运动中、松手后和反向操作的证据。检查跟手、装订与弯折、接触、遮挡和落稳。 |
| 界面给画面留空间 | 在明暗画面与窄窗看透景和焦点。控件位置稳定，只有当前讲述与操作所需的字。入页动效改动时照看画面、布局、显字的先后，并快速连翻，确认只显示当前页内容。 |
| 课堂能接着讲 | 在单屏实走 1920×1080、1366×768 及需要的窄窗，试快翻、暂停续播和切回。检查材料、已提交的物件摆放和机位恢复。实体教室后排可读性单记试讲结果。 |

## 可直接复用的入口

- **实际操作 CLI。** `python -B "Test/course_cli.py" run opening`、`run entry`、`run desk` 对应[功能地图](features/README.md)。`play <操作文件>` 从真实入口按序点选、按键、拖放及截屏，可用 `--desk` 进入独立桌景。操作由 Playwright 发给页面，回归检查读取实际界面、状态变化与截图。
- **正式单屏课页。** 用 `Test/course_cli.py run single_screen` 检查首页和遵义章节入口，再跑开场、讲述、条目、路线和桌景。重剪短片时用 `Test/verify-course-media.py` 的 `--check-join <资源键> <入图键> <出图键>` 核对首尾帧，随后观看实际课页切换。
- **遵义桌景。** `python -B "Test/verify-desk-live.py"` 检查从地图选章或从正常授课进入桌景，核对绕桌、查证、并排阅读和离场回看。`python -B "Test/verify-shot-routes.py" --output-dir ".march-build/镜头验收"` 复跑已有三种镜头实验。
- **全课画面与局部交互。** `node "Test/verify-presentation-policy.mjs"` 检查界面文案规则。于都分流、黎平拖图、乌江机位和遵义携带线索用 `python -B "Test/verify-route-interactions.py"` 复跑，结合实际画面检查。

## 证据和清理

默认报告、动作和截图保存到 `.march-build/验收/` 本次目录。用 `report.json` 的 `passed` 和退出码判断结果，检查关键动作的截图，保存正常速度下的首尾画面对照。CLI 退出即关闭本次浏览器、清理临时 HTML，已保存的报告和截图可继续查看。实体课堂投影、试讲用时和后排可读性单记现场结论。
