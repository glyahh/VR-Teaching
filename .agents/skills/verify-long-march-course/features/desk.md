# 遵义会议桌

## 子功能

按住书角前后翻，短拖松手回落。右册松绳、揭封并拖出散页，手记摘页也可摆上桌。单击已落桌的纸片提近观察。摊图后可以叠看、揭开两条路线。

## 如何进入

地图点「遵义实景」，或从遵义章节进入「会议桌上的两份材料」。点「动手查证」可看当前提示。两册可按任意顺序查。

## 用 CLI 操作

`python -B "Test/course_cli.py" run desk` 通过真实鼠标拖拽查证，保存投影拖页、斜看、纸片近看和重连结果。脚本从每个物件投影出的 `[data-desk-target]` 定位下手点，用可见舞台和实际投影读结果。

## 易错处

两册快捷阅读可在固定画面下使用。实时物件的首帧、书脊、灯影、纸面遮挡和近看字号要从实机判断。离场取消未完成的动作，之后回到同页能查到已提交的页码和位置。
