# 进场及短句显字

## 子功能

从地图、片头、普通课页和回顾进入。画面先出现，边缘布局就位，底部短句随后逐字显示。快速连翻至当前页。

## 如何进入

地图点「开始授课」再点「进入课堂」。在于都集结、岸边备桥、浮桥近景之间用「下一页」或翻页键推进。

## 用 CLI 操作

`python -B "Test/course_cli.py" run entry` 核对各阶段、实际部分显字、短句区域尺寸和快翻。`python -B "Test/course_cli.py" --reduced-motion run entry` 验证直接呈现完整布局。

## 易错处

页面导航必须可用。区分完整的无障碍文本和仍在显字的画面。录屏核对场景与边缘动效的顺序，随后试跨章和回顾重入。
