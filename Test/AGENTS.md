# 课件验收

[上级：仓库指南](../AGENTS.md)

- 可从命令行直接运行的验收入口放在本目录，复用的 Python 操作与断言放在 `support/`。需要随代码分发的测试输入随对应验收保存。
- 改课页用 [course_cli.py](course_cli.py) 实走，改媒体或三维时选对应专项。命令、选测和复跑见[构建发布与验收](../项目文档/长征课/长征课构建发布与验收.md)。
- 正式课件与预览的选择、证据目录和离线要求见[长征课验收技能](../.agents/skills/verify-long-march-course/SKILL.md)。
- 流程回归优先用稳定的操作标识定位控件，验点击、键盘操作和状态结果。按钮文案、字号、形状和样式可随设计调整。涉及布局时验证控件可见、可操作和不遮挡主要内容。字幕、史料文字等教学内容仍按各自要求核对。
- 云端辅助截图超时记在验收报告中。用于判断画面变化的像素截图和实际行为断言继续作为通过条件。
