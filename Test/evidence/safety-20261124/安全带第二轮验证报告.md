同进程两 Worker：视觉初始化 613.9 ms，视觉处理 P50 15.0 ms、P95 23.7 ms；ASR 初始化 1318 ms，WASM 线性内存 512 MiB；整个 Node 进程采样峰值 RSS 883.2 MiB（20 ms 采样，不是 Edge 内存预算）。并发任务总运行 5.706 s。请求区间重叠包含调度时间，不是硬件指令级重叠计量。

## 发现并修复（红→绿）

1. 接受口述与漏讲口述可同时包含归一化后同一句话：检查卡拒绝冲突；分类器运行时仍冲突则弃判。
2. 同一动作重复映射到不同步骤，会使后一步无法完成：拒绝重复动作。
3. 定位/放置步骤没有有效部件仍能通过检查卡校验：拒绝缺失部件。
4. 视图目标与实际切换视图矛盾仍可通过：拒绝矛盾配置。
5. 同时补上非法步骤 ID、空步骤及插入 HTML 时属性转义。全部重新测试通过。

- 语音需用高质量公开中文真人音频、专业术语 TTS 或真实语音样本测试。先对比当前 Zipformer 与其他小型中文 ASR，再按识别正确性、拒判和延时选择；当前八条合成音频不能证明哪种模型更好。
- 当前验证包提供真实 Edge 测试脚本。需在允许 file:// 的 Windows 环境运行成品，不再请求甲方电脑配置作为当前竞赛前置条件。
