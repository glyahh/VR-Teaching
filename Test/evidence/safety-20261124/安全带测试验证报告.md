视觉模型 2,542,856 参数；实际输出 1000 维 ImageNet logits。8 次重复输入最大误差为 0，与 PyTorch 的最大绝对误差为 1.22785568237e-05。这不是安全带识别准确率。

ASR 默认使用 encoder INT8、decoder FP32、joiner INT8。公开 0.wav 与上游参考逐字一致；另一个 8 kHz 样本仍有明显错词，因此不作课堂语音准确率承诺。`clear` 只表示基础信号门，不是识别置信度。WASM 线性内存为 512 MiB，不代表浏览器总内存或教室电脑要求。课程只接受当前卡列出的完整表达，复杂否定和歧义交教师复核。

## 三、本轮发现并修复的问题

1. 简单关键词会把复杂否定或第三人称陈述误判为完成；改为当前卡完整表达匹配，增加反例。
2. 投影心跳超时清屏后，原版本快照会被错误丢弃；修复同版本恢复，并封锁明确结束后的旧会话。
3. 教师接手后迟到授权可能残留采集状态；取消过期请求并停止迟到轨道。
4. 模型尚未完成加载时可以提前结束口述；现在实际进入监听后才允许结束。
5. 相同视觉结果反复到达会撤回教师已公开反馈；仅在反馈语义发生变化时撤回。
6. ORT Blob 模块会错误解析相邻 WASM 地址；显式提供内嵌模块与 WASM 的 Blob URL，上游字节保持原样。
7. 必需打包模块缺失时构建仍可能退出成功；已改为明确失败。
8. 换卡后真人提示和投影视角仍残留硬编码；已改为读取当前检查卡。

## 四、阻断与剩余验收

本地 Chromium 启动被 socket 权限阻止；原生桌面输入通道不可用；云浏览器明确禁止 file://，因此没有继续绕行。尝试把实现与测试上传 GitHub 验证分支时，自动审批拒绝，理由为尚无向该仓库上传代码和文档的明确授权。远程 Windows Edge CI 尚未运行，现有远程分支仍指向原始基线。

下一步需明确授权将本次课件源码、测试、相关文档和 CI 配置上传 `glyahh/VR-Teaching` 的 `verify/safety-harness-20261124` 分支，然后执行真实 Edge 断网空目录、双窗、拒权/迟到授权、设备释放、模型冷启及并发验收，并按失败结果继续修复。

浏览器通过后，正式落地仍需要：实际安全带型号、教师审定的检查卡、同型号正常/偏差/手持/遮挡样本，以及课堂电脑、摄像头和麦克风。须由教师先判的盲测校核误报、漏报与待核率，并记录教室性能。当前没有专用训练数据，也没有已通过盲测的穿戴模型。
