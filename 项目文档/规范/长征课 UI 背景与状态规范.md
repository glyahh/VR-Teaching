# 长征课 UI 背景与状态规范

先辨认当前组件承担的工作，再选底色。新组件有同用途的课件实例时，复用实例的类、变量和状态选择器。当同一组控件叠在一个外框上时，按钮与外框分别按各自的行查找。表中百分比均为**底色不透明度**，0% 表示完全透明。边框、文字、图标、进度标记和背景模糊各自由原组件负责。

| 场景 | 默认 | 选中、悬停与焦点 | 现有实现 |
| --- | --- | --- | --- |
| 正课章节标签、地图时间轴站点 | **0%**，底色和边框透明 | `aria-current` 用约 **10% 金色底**、金色边框和文字。可用项悬停用约 **8% 暖白底**，包括当前项悬停时的底色。键盘焦点使用细金轮廓。 | [章节标签与状态](../../课堂演示/自由探索实验/lesson-rails.css#L10) |
| 直接叠在画面上的圆点热点、回顾站点外层、三维右上短说明 | **0%** | 热点由圆点响应，回顾站点按钮悬停时外层仍透明，其站名标签按自身样式显示。三维短说明用文字阴影维持可读性。 | [热点](../../课堂演示/自由探索实验/exploration-stage.css#L57) · [回顾站点](../../课堂演示/src/style.css#L296) · [三维说明](../../课堂演示/src/exploration-page.css#L113) |
| 片头四站时间轴、共用左下讲述框和其中的热点说明 | **10% 暖灰底**，细边、轻微模糊 | 时间轴节点点亮、讲述进度和继续提示用自身的颜色与状态。底板沿用 `.copy-panel`。 | [文案底板](../../课堂演示/src/style.css#L101) |
| 地图缩放、视角、重置的组合外框 | **22% 深色底** | 组内可操作按钮按其现有按钮类处理悬停和焦点。 | [地图工具外框](../../课堂演示/src/style.css#L70) |
| 播放、暂停、全屏、音量、返回地图等常规按钮 | **53% 深色底** | 可用按钮悬停用 **72% 深色底**。已选或已开状态沿用组件的 `aria-pressed` 样式，有的只改变边框，有的使用金色。键盘焦点沿用轮廓，禁用项沿用禁用样式。 | [普通按钮与状态](../../课堂演示/src/style.css#L3) |
| 地图章节预览卡、课堂回顾卡 | **54% 深色卡片底** | 卡片承载内容，卡内按钮分别使用相应按钮状态。 | [地图卡](../../课堂演示/src/style.css#L54) · [回顾卡](../../课堂演示/src/style.css#L310) |
| 片头和场景短片字幕、片头地点角标、练习面板与资料弹窗 | **66% 深色底** | 字幕按现有播放规则显示。练习或弹窗内的选项反馈沿用原组件状态。 | [底色变量](../../课堂演示/src/style.css#L3) · [字幕与角标](../../课堂演示/src/style.css#L343) |
| 「开始授课」「进入课堂」等现有金色主操作 | **84% 金色底** | 可用按钮悬停用 **93% 金色底**，沿用主操作的细边及键盘焦点。 | [主按钮](../../课堂演示/src/style.css#L16) |

同一课页可以同时选用多种底色。例如，片头时间轴用暖灰 10%，下方字幕用深色 66%，右上同排的「进入课堂」与播放按钮分别使用金色主按钮与普通按钮。调整位置或交互时，底色随组件用途和状态选择。遇到已有场景专用样式的控件，先查该选择器和运行状态，再决定是否复用表内样式。

- 调整讲述框的排版、进度或片头时间轴的构成时，参考[文案叠层实现](../../.agents/skills/copy-panel-overlay/SKILL.md)。调整底栏的位置与排列时，参考[课件贴底导航栏](../../.agents/skills/lesson-bottom-rail/SKILL.md)。
- 在实际课页核对默认、选中、悬停和键盘焦点这些涉及的状态，查看明暗背景与窄窗。由 [长征课验收技能](../../.agents/skills/verify-long-march-course/SKILL.md)选择入口。变更前以正式课件的 CSS 和计算样式为准。
