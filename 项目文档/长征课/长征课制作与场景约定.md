# 长征课制作与场景约定

[长征课文档指南](AGENTS.md) · [仓库指南](../../AGENTS.md)

## 制作与场景规则

- 教学视频、场景动效和交互反馈遵循[长征课视觉与动效规范](../规范/长征课视觉与动效规范.md)。分镜、参考图、OpenMotion 和首尾帧审片按其中的短片规范执行。
- 视频片源可沿两条路径获取。检索授权素材时记录出处、许可、署名和截取区间；需要生成时，用 [Generate Video 技能](../../.agents/skill-packages/generate-video/SKILL.md) 提交、查询原任务和下载，再把本地片源交给 OpenMotion 剪辑。密钥留在本机凭据或进程环境变量，正式课件只打包通过验收的成片。
- 新建或精修三维模型只用于确有需要的实时三维交互。按实际可走动、可绕看和可操作的范围确定资产清单。优先复用项目和授权可用的专业资产，外部检索、精修与离线打包按[三维交互素材工作流](#三维交互素材工作流)执行。
- 新增模型、材质、图片、视频或常规交互时，先查本项目已有资产，再主动上网查官方史料、成熟素材库和 GitHub 开源实现。找到符合场景、许可和技术要求的资源就下载复用，按课件风格和运行环境调整。优先查看上游的维护记录、可运行示例和实际用途，余下的具体缺口再自制。采用时记下来源、许可证和代码版本，保留适用的许可声明，并在实际课件中验收导入效果和离线运行。
- 长征课按[冻结版最高执行标准](../../项目文档/长征课/长征沉浸式VR党课落地方案.md#冻结版最高执行标准)为每段选择表现。18 分钟和 30 分钟的快讲安排、讲稿和累计卡点仍可从课表和项目资料查阅。
- 适合自由探索的长征段落，先依据史料明确当时人的困难和可用条件。把处境、人物行动和看得见的变化放进可走动的场景，让学员自己观察、操作和回看。与先辈产生共鸣、对处境有换位思考，是场景背后的设计意图。用少数关键停留点与对应材料说明当时的条件、选择和后果，动作细节尽量由画面交代。
- 按空间尺度选择操控。室内和中等尺度场景优先试第一人称步行，鼠标右拖向右看、下拖向下看。河岸、湖面等大空间优先试俯视视角，支持环绕、俯仰、平移和缩放。用于自由探索的最小原型要让学习者直接改变物件，按场景安排翻合、拨动、拖放、剖看等操作，现场验收运动中、松手后和反向操作时的画面。
- 历史场景的任务从史料里的具体制约出发，让学员从地形、材料、队伍或人物反应中找到线索。保留不同做法可观察、可重复比较的后果。入口只给当前可做的一步，其余提示随现场和操作逐步出现。课堂推演的组数、时间和布局注明为示意。
- 教师点播的演示可暂停和原位继续，段末保留证据画面。正式课件「浮桥近景」点一次「于都河岸」，按铺门板、看桥下、到桥头、夜渡、撤桥的顺序连播，镜头、旁白和字幕同步。河岸短片沿用课程片头的整页画面，标题在左上、控件在右上、字幕贴底居中，留出中央动作区；窄窗保留完整画幅。播放开始即显示「进入河岸」，点击后暂停短片并加载三维，返回后保留播放位置。用断网试播核对镜头与字幕、画幅、片尾及暂停续播。
- 于都河岸固定讲述用参考图和 OpenMotion 视频作教学复原。正式三维用于观察河面、近岸草地、湿土和船桥构件。「渡河计划」显示要点和时段，面板以「夜渡」「收桥后」同机位回看按钮收尾，出处见冻结落地方案。检查水线、草丛、构件接触与两时点的同一观察机位。
- 「湘江渡口」用 Generate Video 制作的写实视频呈现渡江经过，成片在 OpenMotion 剪辑。短片播完从解码尾帧自动进入「湘江留下的启示」。窄窗先从完整视频画幅过渡到下一页的构图，暂停期间停在原处。核对字幕时点、尾帧交接及断网播放。队伍人数和路线为课堂示意。[湘江渡口短片](../../课堂演示/media-source/xiang-crossing-tour.md)
- 回顾可按站回看。站点悬停时透明，鼠标按下时保持地图锚点，点开后卡片避开顶部和底部控件。用 `run recap` 实走鼠标、键盘、回看和返回。片尾用已见过的画面与路线串联，收在遵义破晓并允许停留。结束画面与播放期间都可一键「返回地图」，断网验证暂停、续播和重播。
- 于都五镜按每镜约三到四秒组织，核对抬起、承托落稳和松手的先后。连播成片的复剪和河岸贴图来源见[于都河岸短片与材质](../../课堂演示/media-source/yudu-shorts.md)。
- 于都五镜与课程片头共用云健音色、语速、音高与人声处理参数。换音轨时核对每句的起止与镜头边界，并将正式 HTML 单独复制到空目录断网试播。
- 样课在同一页面切换场景，保留各自机位、已取线索和演示进度。切走时暂停，返回后从原处继续。用短过渡交代切换，允许再次选场景。材料收起后焦点回到入口，系统启用「减少动态效果」时直接显示对应状态。
- 第一人称场景按住移动键时隐藏标题、导航、热点和提示框。松开最后一个移动键后一起渐显。浏览器失焦或切场时清除按键状态。
- 长征课美术以自然写实为准，减少 AI 生成感。重点模型用参考校对比例、结构和材质，实际从远近及不同角度核对光影、部件连接和接触。界面只留操作与阅读所需的内容，操作立即回应，场景、素材和三维物件的切换短而连贯。
- 建模精度优先给课堂需要近看或操作的物件。书册检查书衣、装订、纸叶、书口和卷首文字。搬运场面核对手掌、脚踏面与物件承托。大面积背景用可复用贴图和简洁轮廓，验收以课件实际观察机位为准。
- 片头人物出现肢体扭曲时，用正式源帧定位肩、肘、腕和指节，核对握持、承托和脚部落点。用参考图和原机位校对替换镜头，按原速、慢速和关键动作逐帧验收。群体另查负重姿态、步态差异和换步接缝。
- 长征课正式界面共用半透明背景与毛玻璃控件。视频页沿用普通课页的标题层级、左下毛玻璃文字框和章节细线导航。文字位于视频画幅外时，用同一短片画面的虚化底衬贯通顶部和底部。按钮用半透明细边，主要操作用金色。材料原有纸面保持可读。核对明暗背景、窄窗、选中状态以及暂停续播的位置。
- 演示交互、史料与出处都在课件内。普通课页共用左下讲述框，三维场内短说明放右上。验收时打开史料、材料和场景切换，检查可操作入口与提示位置。
- 长征课的重点交互要能连续操作与回看，全课在合适的段落安排不同玩法。验收时实际翻阅手记、拨动行军图、操作或剖看构件，核对物件状态与反馈，再从正常入口回到原来的演示。只打开同类卡片的圆点用于导航。
- 遵义会议桌点物后进入同页正视阅读，退出恢复进入前的机位。桌上保留直接翻页、解绳、揭封、移放和叠图。手记用整页拖动或点击翻页，行军图可单看、叠加和同尺度并排。单屏实测取消、连续反向操作、图例可读性和查证状态恢复。
- 遵义桌景的活动纸件和灯火使用实时网格。更换前景道具时，从房间参考机位去掉同一物件，避免成像叠影。前后版用同一机位、窗口、手势和光照条件录制，逐帧看书脊、折线、桌面接触及玻璃内外层。
- 长征课并行检查交互多样性和场景连贯。转场让上一场的动作、物件、视线、路线或环境声引到下一场，解释文字留给按需打开的材料。用实际课件正常速度连看出场、过渡和入场，确认注意点和情节接得上。
- 长征课讲述每段讲清一件事。用 `humanizer` 和 pstack 的 `unslop` 审一次改动文案，按实际讲授顺序朗读，再核对史料。口语自然度、史实准确性和教室后排可读性由实际审读、试讲验收。
- 长征课片头优先以经过许可核验的外部实拍和情境资料承载主要画面。项目图片用于构图参考和课页接缝。按实际播放首尾对位，来源与许可随剪辑记录。
- 片头换镜以正式片逐镜解码确认范围，保留原机位与同一动作阶段的画面对照，再比完整运动镜头。仅改画面时核对原声、字幕时码、叠化及离线播放。既有 Blender 源工程与渲染记录用于追溯片源。
- 向网页端视频工具交付长征互动短镜头时，按实测出片时长安排完整动作。Gemini 网页实测输出 10 秒时，用 10 秒安排原片动作。提示词写清课程情境、学员选择和动作的起因与结果。同一场景入片时，首帧与实景入片画面对齐，验收时叠看开头半秒。尾段可自然进下一场或回到三维场景，验收时连同实际下一个画面播放。指定使用 Gemini 会员用量时，通过已登录该会员的 Gemini 网页生成，额度用尽后等其恢复。重试前先核对原对话中的附件、任务和已有影片。下载中断时从同一结果取回。
- 由多个视频素材组成长征短片时，把搬运、放稳、检查等关键动作分到可独立审看的机位。先复用已合格的段落，再为缺的动作准备单独参考帧。逐条检查接触和承托，仅把通过的片段剪入成片。成片时长和入场、收场由本地剪辑决定。
- 用户自己在 Gemini 制作时，回复只给可直接粘贴的生成提示词、首帧和尾帧图片文件名。使用参考图时写云盘完整文件名及扩展名。原始素材可自然收镜，尾帧栏写“无需上传”时，仍以演示后图核对剪辑成片的尾帧。用户明确要 Antigravity 工作流时再给启动指令。
- 长征课按访谈、甲方最新通知和用户纠正确定课堂目标与交付范围。工程选型先查本项目、开源社区和上游文档，X 等社区演示可作线索，用本地课件或目标设备核实。可逆的制作细节由技术侧决定。涉及课程目标或重大范围取舍，已有资料仍不够时，再用课堂场景向课程方核实。

## 素材与展示材料

- 正式课件从遵义章节进入会议桌。`desk-world.js` 绘制共用深度的室内场景与实时纸件，`desk-live-session.ts` 处理操作预览和松手后的提交。离场回看恢复页码、机位和已提交的纸件落点。修改模型后按[实景授课与复建说明](../../展示材料/遵义会议室精修场景/场景与素材.md)更新空间资产。

- 遵义桌边精修场景的建模和材质准备脚本在 `课堂演示/media-source/desk-study/`。可编辑 Blender 工程、两个机位的渲染图及[素材来源与复建命令](../../展示材料/遵义会议室精修场景/场景与素材.md)在 `展示材料/遵义会议室精修场景/`。用 `Test/verify-desk-study.py` 从单独复制的工程重渲，验证贴图已内嵌。

- 更新课件素材时，将运行文件放入 `课堂演示/assets/`。新增或更名时按[运行素材指南](../../课堂演示/assets/AGENTS.md)核对清单和资源键。素材说明记录画面和材料的制作类型，教学资料保留史料出处。重建后断网检查相关场景。
- 「开始授课」播放纪实导览，长度和自然结束流程见[画面与短片的安排](长征沉浸式VR党课落地方案.md#画面与短片的安排)。片头保留云健旁白和底部单行字幕，按字幕长度和窗口宽度调字。进度条默认隐藏，鼠标悬停底部或用键盘聚焦时显示。拖动后画面、配音和字幕按同一时点播放或停留。回地图、重播或拖回片中时取消片尾等待。开场计入地图导入，音频由主控播放。
- 片头湘江涉水镜头保留字幕与原声。四站时间轴的日期、圆点和站名共用网格，进度线在首末圆点的中心之间推进，抵达节点时点亮。用 `run opening` 在横屏与窄窗核对遮挡、逐站点亮及暂停续播。
- 片头外部素材的来源、许可、分镜与离线重剪方式见[片头素材](../../课堂演示/media-source/opening-sources.md)。
- 于都备桥短片由 `课堂演示/media-source/make-yudu-preparation.py` 剪辑。传入经核对的原始抬送视频和输出路径，产物为 `课堂演示/assets/yudu-preparation.mp4`。用单屏脚本检查 Edge 实际解码首尾帧、归位、暂停续播和回到浮桥的画面。
- 正式课件在「浮桥近景」播放期间或片尾点「进入河岸」，同页打开三维。与样课共用 `river.js` 和 `课堂演示/assets/yudu-river/`。退出三维回到视频原位置，重新打开恢复三维机位。媒体或三维加载失败时可继续授课。
- 「遵义会议室」同页打开材料厅。两个三维场景共用 `exploration-stage.js`，每窗使用同一张三维画布。正式课件和样课从 `exploration-assets.mjs` 打包运行素材。湘江短片更新后，先运行 `python -B "课堂演示/media-source/make-xiang-poster.py"` 生成与 Edge 解码首帧对应的静图，再重建课件。
- 既有遵义短片的 Blender 4.5 与 FFmpeg 复建命令见 `课堂演示/media-source/render-zunyi.py`，渲染依赖为 `makehuman-base.obj.gz`。制作替换片段时按 OpenMotion 规则执行，核对成片与 `zunyi.png`、桌面材料热点及下一画面的对应位置。
- 在 `展示材料/演示文稿/` 或 `展示材料/报告/` 选择对应版本，用 PowerPoint 或 Word 编辑。若本地已有对应生成脚本，可从 `.march-build/`、`.vr-demo-build/` 或 `.vr-lesson-build/` 修改源脚本后重导出。将最终文件单独复制到空目录，断网用 PowerPoint 从头放映，检查交互跳转、返回和内嵌媒体。在 Word 打印布局中检查分页、字体、图表及文字是否被裁切。

### 三维交互素材工作流

1. 由 Codex 查看仓库已有素材和实际课页的参考图，按操作任务列出待补资产的用途、尺寸、画风、面数预算、贴图和动作。模型、PBR 材质和 HDRI 分别检索。河岸可用 `grass tuft`、`riverbank grass`、`water ripples`、`calm lake reflection` 起查。
2. 优先用 Sozai Search（`sozai`）和 3D Valley（`3dvalley`）MCP 执行 `search_assets`，用 `get_asset` 核对候选的来源、许可、尺寸、面数和贴图。Sozai 可用英文短词、`alternatives` 和 `redistributable_only=true` 筛查。两边不足时，特殊历史道具查 Sketchfab 并对照官方史料，人物与动作查 Mixamo、CMU 动作捕捉库或 Quaternius，建筑及场景查 BlenderKit 或 Fab，模型、贴图和 HDRI 也可查 Poly Haven 与 ambientCG。逐件核对许可、署名和是否允许随离线课件再分发。
3. 把候选下载到 `.march-build/` 下的任务目录。Sozai 用 `fetch_asset` 传绝对路径，先用 `quality: "web"` 下载 1K 或自包含 GLB，保留生成的 `CREDITS.md`。3D Valley 用 `get_asset` 返回的文件链接下载对应格式和分辨率，核对字节数及其提供的校验值，保存返回的署名。留存上游链接、资产 ID、许可、版本或文件哈希。模型检查实际三角面数、轴向、尺寸和内嵌贴图，材质检查分辨率、贴图种类和法线方向。
4. 必要时用 Blender MCP 精修比例、材质、骨骼和动作，统一导出 GLB。用 glTF Transform 按课件需要优化、减面和压缩，在目标机检查材质、动画和解码。验收后的资产按场景归入 `课堂演示/assets/`，作为 Three.js 与 OpenMontage 可共用的本地 GLB 资产，同步素材说明和打包清单，并从正式课页断网验收。河面反射 HDRI、液态水表面法线与河床材质分别按水况选用。

河岸实测中，两套 MCP 都检索并下载了 Grass Bermuda 01 的 1K GLB 和 Arboretum 的 1K HDRI。Sozai 另下载了近岸 Grass Path 3 的 PBR 贴图，3D Valley 另下载了有 OpenGL 和 DirectX 法线的雨滴水洼材质。雨滴水洼用于验证下载和贴图内容，实际河面按场景水况选用。 [Sozai Search](https://github.com/kanaworksai-hue/sozai-search-mcp) · [3D Valley MCP](https://3dvalley.com/mcp-server)
