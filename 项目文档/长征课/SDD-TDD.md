## 第一层｜课堂验收

### 课堂 Agent 上下文验收

| 编号 | 流程及通过条件 |
| --- | --- |
| A-01 | 混合交互至少 50 次。按事件 ID 查回早期错误、质询原题、反馈、材料与修正，复盘输入仍能关联它们。 |
| A-02 | 质询发起后翻阅材料、切页返回、刷新。原题、活动阶段、最新反馈和已阅材料保持一致。动作仅在课件核实结果后记为完成。 |
| A-03 | 低预算触发语义摘要，逐次核对输入预算、六条事实和当前完整输入。保留原始记录及证据 ID，区分学员假设、模型反馈和课件操作。 |
| A-04 | 在摘要进行时新增事件、发出重复请求及重新开课。旧结果只能提交到原课堂的对应范围，新增事件继续可查。失败、取消或无收益时保留原始记录并走确定性装配。 |
| A-05 | 对损坏及旧版快照、存储写入失败、摘要非法 JSON 和超时做降级验收。受保护内容超限时返回预算错误。 |
| A-06 | 用相同输入比较旧截断、完整轨迹和新装配。分别记录事实保留、合法输出、输入用量、时间和摘要模型调用次数。模拟与真实用量分开记录。回归 Edge 四项 AI、复盘导出和离线零请求。 |

基线使用现有网关测试捕获实际兼容请求。副导、沙盘、质询和复盘的系统消息与本轮输入分别为 4565 与 209、3436 与 200、3554 与 149、3906 与 197 个 UTF-8 字节。该样本含规则、六条事实和输出字段约定，未包含长历史。改动后通过真实端点的 usage 核对保守估算。对照记录由 `Test/verify-course-context.mjs` 写入 `.march-build/context-acceptance/`，Edge 真实用量随验收目录保存。

长征课教师把一个 HTML 文件复制到课堂电脑，用 Edge 打开地图并开始授课。学生从投影跟着看，教师可以暂停、翻页、打开史料和回到现场。课页衔接由画面交代，学生能通过实际操作观察物件变化。40 分钟为主线，50 分钟含深化内容，18 和 30 分钟沿用现有快讲。

安全带课拟围绕课程方审定的岗位训练任务，让学员先看引导，再独立完成模拟训练和评价，发现错误后重练。二维点选、拖放和真人实物反馈是候选方案。真人范围拟先选一种型号、一个看得清的部位和一句必讲内容。看不清就重摆，没听清就重说，确认偏差或漏讲才给纠正提示。教师复核实物，设备不可用时可用参考图和教师判读继续。

长征课以一份独立离线 HTML 交付。教师决定展示哪些材料。界面只保留当前要看的画面、要做的操作和必要反馈。真实教室的投影可读性、可控性和节奏由本人和授课教师试讲确认。

### TDD 怎么跑

1. 先写操作、可见结果与相邻行为。修 Bug 时从正式入口缩小错例，优先扩展最接近的现有用例。无法稳定自动化的现象，用可重复的真实操作、录屏或设备实测，并说明为什么。
2. 对旧成品或未实现代码跑一次，检查失败来自目标行为。环境缺依赖、窗口没打开或夹具坏了，先修验证。新规则直接给一组明确输入和期望，关键浏览器行为检查画面和状态，不依赖私有函数调用次数或固定等待。
