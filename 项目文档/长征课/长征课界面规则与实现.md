# 长征课界面规则与实现

[长征课文档指南](AGENTS.md) · [仓库指南](../../AGENTS.md)

开发界面前，按用途和状态从[技能索引](../../.agents/AGENTS.md)选择项目技能。

| 界面规则 | 执行位置 |
| --- | --- |
| 新建或调整组件底色时，按[长征课 UI 背景与状态规范](<../规范/长征课 UI 背景与状态规范.md>)匹配用途、默认状态、选中态和悬停态。 | 共用底色在 `style.css` 和 `lesson-rails.css`。`run opening`、`run entry` 与 `run narration` 检查当前入口的底板与可读性。 |
| 展示面以画面交代事实，文字留给必要的地名、操作和当前反馈。设计说明、来源和规格存项目记录或按需打开的材料。 | `page-policy.mjs` 拦截已有的说明性标签和探查计数样式。`node "Test/verify-presentation-policy.mjs"` 用旧课件片段验证规则，实走课件核对其余文案。 |
| 章节切换用横向细线导航，当前项用金色细框。连续史实、卷宗要点和课堂回顾用纵向细线与圆点，真实的日期和地点排在节点标题上方。 | 正式课件、独立样课和成果页共用 `lesson-rails.css`。`course_cli.py` 验收正式课件中的章节切换、节点揭示和回看。 |
| 调整正式课页或地图的常驻导航时，按 [课件贴底导航栏](../../.agents/skills/lesson-bottom-rail/SKILL.md) 选择布局。 | `lesson-page.ts` 和 `lesson-map.ts` 分别维护课页与地图控件，`style.css` 的 `.bottom-rail` 统一间距。`run entry`、`run controls`、`run narration` 和 `run recap` 核对实际入口。 |
| 画面中的点选入口用圆点定位，通过无障碍名称描述对象。翻合、拨动、拖放、拆看等操作由场景对象直接回应。 | `markScenePoint` 负责圆点。`course_cli.py run single_screen` 验入口，`verify-exploration-prototypes.py` 实走物件操作与回看。 |
| 导览在课堂开头。会议桌保留手动观察、查证和材料状态。 | 开场与桌景各有入口，`verify-course-media.py` 验导览首尾帧，`run opening` 验播放和续播，`verify-desk-live.py` 验桌景定格与手动查证。 |
| 画面、边缘布局、讲述依次进场。圆点说明共用左下框，点空白可补完当前段或推进下一段。 | `page-entry.ts` 在布局后启动 `scene-lesson.ts` 的首段。后者按访问轮次同步。界面检查拦截旧圆点框。`Test/course_cli.py run entry` 和 `run narration` 实测。 |
| 讲述一行用一行高度，最多两行，旧行留够阅读时间再从上沿淡出。 | `narration.ts` 按实际排版计时，只渲染两行。`run narration` 检查湘江河谷单行高度、窄窗淡出、末字。 |
| 遵义军事、组织和转折三页逐项开合，三条转折依据看过后才显示本页结论。 | `StoryPage` 约束内容，`scene-lesson.ts` 只保存一个展开项，结论由已看条目推导。界面检查拦截旧批量入口，`run disclosures` 验证乱序、练习返回与重新开课重置。 |
| 于都至湘江、湘江至黎平先在有地名的近景描线，再拉远短停，接入下一课页。 | `route-scenes.ts` 用 `content.ts` 的地理数据投影路线与地名，完成后交给进场器。`run journeys` 实走路线与快翻。 |
| 场内说明右上轻透，循环背景自动播放，河岸视频文字沿画面边缘放置。 | 场内说明共用 `.scene-note`。`run controls` 检查窄窗和背景播放，`Test/verify-yudu-shorts.py` 验证画面铺满、按钮对比度、连播、播放中进入河岸及返回原位续播。 |
| 总览地图底栏右侧是工具，卡片可拖动并在地图边界内减速停下。 | `map-card.ts` 统一处理拖动、惯性和边界，`run controls` 实测宽窄布局、滑行与卡片按钮。 |
