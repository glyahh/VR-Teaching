# 长征沉浸式党课《从于都到遵义》落地方案

## 冻结版最高执行标准

**v1.17 已冻结，2026 年 11 月 27 日。** 片头四站时间轴与左下讲述框共用「10%透明度文案装用背景板」。 片头采用 120 秒连续纪实导览，重点交代湘江受挫至黎平改向。沿用原播放界面和云健配音，字幕始终单行，底部进度条默认隐藏，鼠标悬停或键盘聚焦后可拖动或跳转。新制视频优先用 OpenMotion 以参考图生成镜头，三维建模限于实时交互所需。「湘江渡口」统一用视频呈现，播完从尾帧自动接入「湘江留下的启示」。「渡河计划」面板以回看按钮收尾，史料出处见本文。正式版 `main` 为单屏授课。v1.11 优先打磨课尾，其次深化湘江、猴场、乌江与遵义相似课页，精修于都史料、遵义材料厅和会议桌。于都河岸短片保留整页画面、贴底字幕及播放中的河岸入口。旧版的教师备课、试讲、教师视图、双屏及首页实景入口已归档。 [原版归档分支](https://github.com/glyahh/VR-Teaching/tree/codex/teacher-prep-archive)

整堂课按 **40–50 分钟**备课。以 40 分钟主线和可按需展开的 10 分钟深化内容安排授课。

1. **在多个合适的段落安排可玩的现场。** 依据史料呈现先辈当时的处境、选择和行动。让学员自由观察、选择顺序、动手并看到与操作相关的现场变化。全课核对各段可做的事，按实际任务搭配漫游、转看、翻合、拨动、拖放、拆看、路线对照或分段演示。重点交互场景在同一空间安排多处可深入操作的对象或任务。圆点可以定位和打开材料，重复点开同类卡片只算一种入口。把故事的原因和后果落在学员能观察、操作和比较的画面里。
2. **每段选能讲清过程的表现方式。** 路线变化、物件动作、局部动画和纪实短片按教学需要使用。点选、拖动和切换立即回应，动作连贯、快速、短而精，完整看得到关键的接触、承托和结果，段末留下可观察画面。**短片首帧和尾帧分别吻合正式课件实际入片和出片的图片或三维机位。** 核对构图、裁切、光线和物件姿态，在正常速度下播放两处衔接，观察有无跳位、明暗突变、黑帧或等待。教师可暂停并从原处继续。

   **场景之间用画面、动作或声音承接，转场不加解释文字。** 从上一场的动作、物件、视线或路线出发，引到下一场的观察对象。换地点可以沿地图路线或空间动线进入，动作可以由同一物件的变化接续，环境声可以提前带出下一场。根据两场的关系选用，让观众看懂画面到了哪里、为什么接着看这一幕。

   **进场先画面，再布局，后出短句。** 画面和边缘布局就位后，自动开始首段讲述。空白点击或全局空格键先补完正在显字的主讲，再推进下一段；打字中被圆点打断时，点空白先补完原句再续进。主讲与圆点说明共用左下框，最多两行，旧行读完后从上沿淡出，并以非文字化微光刻度条和续读动效提示进度。正课按场景提供低噪环境音景与轻量交互音效，在当前课页播放并保留静音开关。快翻和跳章按当前页收束。开场导览以有明确来源与许可的外部实拍和情境镜头为主，选定图片参考构图或承担首尾衔接，内嵌后离线播放。

   于都至湘江、湘江至黎平、黎平至猴场、猴场至乌江、乌江至遵义五段跨站转移均在 3D 立体地形上以具体地名近景描线，再拉远短停并接入下一课页；黎平至猴场同时以虚线对照湘西北原计划。通道地名按县溪镇通道转兵纪念馆附近定位，沿途路线为课堂示意。 [通道转兵纪念馆](https://wwj.hunan.gov.cn/wwj/c100312/201705/t20170508_10479126.html)
3. **三维场景经得起换角度和近看。** 用实物或可靠参考核对比例、结构、材质和光影。沿实际可到的机位检查正常远景、操作近景和侧后方。门窗、家具、地面、岸边和背景等可见环境，即使不承担交互，也要交代清楚场所和时代。重点物件细化到学员会观察的部件、连接、接触和遮挡，背景细节按实际观察尺度安排。于都河岸、遵义材料厅与遵义会议桌作为可交互三维现场：材料厅支持点选远处圆点自动平滑漫步前往并携带全部已查线索进入会议桌；会议桌默认直接可手动翻阅、解绳、揭封、拖页与叠图，悬停件微抬高光反馈。
4. **界面透明简约，画面承担主要讲述。** 地图、视频、课堂、三维和回顾共用透明叠层和毛玻璃控件。章节底栏透出画面，按钮保留细边和金色主操作，字幕与讲述框采用轻透深底。河岸短片沿用课程片头的整页画面，标题放左上，控件放右上，字幕贴底居中，播放时收起章节栏，留出中央动作区。窄窗按原比例显示完整视频。验收核对文字、按钮和选中状态在明暗场景都读得清。默认画面只留必要的地名、日期、操作、关键数字和当前反馈，保留 13px 无文字场内小圆点，首页立体地图标注于都、湘江、黎平、遵义四站地名。解释、史实出处与较长内容放到按需打开的材料或教学资料。设计理由、制作规格与验收条件留在项目记录和测试里。

   三维场内短说明放右上，循环背景随课页播放。在「浮桥近景」点一次「于都河岸」，连续播放五镜教学复原视频，保留暂停、原位续播和片尾定格。播放开始即显示「进入河岸」。点击后暂停视频及加载实时三维，返回后可从原位置继续播放。无人物的三维现场保留构件剖看、史料与夜渡和收桥后同机位回看。撤下正式课件的分流对照及其课堂推演数据。地图工具与时间轴共用底栏。黎平方向推演按钮点击后保持常驻，五处场景练习末题核对后切为主按钮「完成练习」。遵义的转折页在三条依据都看过后显示本页结论。
5. **主动查找并复用成熟资源。** 先查工程里已有的素材和实现，再主动上网找实拍、成熟素材库和 GitHub 开源代码。记录采用素材的来源、许可与版本。新制视频按分镜复用参考图或按场景生图，用 OpenMotion 制作，核对实际解码首尾帧与前后课页，尤其是尾帧与下一张图或三维机位的匹配。实时三维先复用必要的模型、材质和动作，仍有具体交互缺口时再建模。 [三维交互素材工作流](../../AGENTS.md#三维交互素材工作流)

### 改动范围与验收

开始改动前，记下任务起点、用户点到的课页、场景或镜头、它要解决的问题，以及用来对照的现有体验。以已回滚的 `e7ef792` 为本次要求的参考成品。只把已明确适用于全课的要求用到全课。调整一个阶段的故事、底板或操作时，课序、导览、窗口、其他场景与交付形态各按自己的目的和明确需求决定。确需改动共享实现时，说明相关入口为什么受影响，并回归实际使用。会改变已确认体验的扩大改动，先核实具体对象和理由。

近期并行解决交互单一和场景衔接。找出只有同类点选的段落，也找出换场后注意点或情节接不上的位置。逐段确定可以深化的操作，以及能把前后场连起来的画面或声音。验收用各段实际的教学任务和课件流程。

| 核对内容 | 验收要看到什么 |
| --- | --- |
| 改动范围 | 用 `Test/verify-lesson-scope.mjs` 对照任务起点和声明范围。`--allow` 声明可整文件修改的路径，`--range` 声明共享文本文件中可改的基线行号。脚本会拦截范围外的文件和文本区段。共用代码的体验影响通过实际课件复查。 |
| 交互深度和覆盖 | 从课件的正常入口走到改动处，试该段允许的不同顺序或打法。能在画面里指出每项操作改变了什么，拖放或翻合要核对运动中、松手后和反向操作。按章列出实际可体验的场景和动作，再判断全课是否仍集中在同一种点选。 |
| 场景承接 | 在正式课件里按正常速度连看上一场末尾、过渡和下一场入场。观察者从画面和环境声能指出承接线索，跟住原来的关注点，看懂地点、动作或情节为何这样推进。 |
| 模型与界面 | 录屏或截图留存远景、近景和另一机位，核对互动对象及其周围可见细节。界面在明暗背景和目标窗口下都能透景、看清文字和操作。 |
| 动画与出入片 | 留存实际入片、解码首帧、解码尾帧和实际出片画面，逐对叠看并正常播放。对已内嵌的短片和图片，可用 `Test/verify-course-media.py --check-join` 先筛查首尾差异，再核对正常机位、绕看后的入场、段末停留及暂停续播。 |

## 三维探索与场景讲解

三维探索希望学员理解革命先辈的处境，与他们产生共鸣。换位思考是场景背后的设计意图。先依据史料把当时的难处、能用的条件和人物的行动放进现场，让学员在走动和观察中慢慢看明白，为什么他们会作出这样的选择。创新体现在学员能沿自己的路线看见这层因果。

| 部分 | 怎样制作 | 课堂上怎样用 |
| --- | --- | --- |
| **三维自由探索** | 用在值得学员走进去探查的段落。先定当时的处境，再安排可走到的地点、能操作的物件和会发生的变化。场内提示围绕眼前可做的事。 | 学员可以按自己的顺序去看、动手和回看，从不同位置发现处境和行动之间的关系。教师顺着学员注意到的细节补充史实。 |
| **课件场景讲解** | 根据教学内容搭配路线动画、物件动作和纪实短片。同一场景根据观察或操作呈现有用的变化。剪短片前确定课件里实际切入和接回的画面，从原片挑出有效动作，首尾帧分别对齐。 | 教师按讲解进度演示。需要看清某段过程时，从当前画面接入短片。播完自然回到当前场景或进入下一处，教师接着讲。 |

三维部分可先用遵义试做。学员从入口走到路线图或材料桌，自选先后。路线图上能对照来路，材料桌上能翻阅会前记录。前后两处的线索让学员慢慢看懂会前仍有哪些难处、为什么要坐下来讨论。先走通观察和操作，再细化门窗、家具和人物动作。

以于都备桥为例。课件先显示河岸备料，短片从同一构图进入抬送门板的动作，再交代架成后的浮桥及船体承托。片尾落在浮桥近景，教师继续指认桥板和船体。素材到位后，按课堂要讲的过程挑选可用段落，用实际课件的出入片画面确定画幅和裁切。[岸边前图](../../课堂演示/assets/yudu-bank.jpg) · [备桥衔接样片](../../课堂演示/assets/yudu-preparation.mp4) · [浮桥后图](../../课堂演示/assets/yudu-bridge.jpg)

每段剪辑前确认「入片画面、要看清的过程、出片画面」。参考可以是静图，也可以是课件里的三维机位。回到原画面时，两端可用同一画面作参照。接到另一地点时，短片内先交代场景变化，片尾再对齐后续画面。教师按需暂停讲解。

| 验收内容 | 实际要看到的结果 |
| --- | --- |
| 三维探索 | 在该探索段从同一入口走到不同地点，试不同顺序，检查操作反馈和回看。试讲时听学员主动提到哪些细节，观察他能否把当时的处境与先辈的行动联系起来。 |
| 纪实短片 | 在真实课件里连看入片画面、短片和出片画面。用解码后的首、尾帧分别核对画幅、裁切、主体位置、大小、明暗和物件状态。按正常速度检查两端衔接、操作等待和讲解接续。 |
| 美术和交互 | 用参考图核对重点模型的比例、结构和材质。从远近及不同角度实际操作，检查整体光影、物件接触、反馈速度和连续性。 |

遵义材料厅可从正式课件的「遵义会议室」进入。学员可先看行军图或先翻手记，退出材料厅后再到会议桌对读。离线课件验收中实走两种顺序，并核对备桥片从岸边到浮桥的衔接。课堂试讲记录学员取得证据、解释处境和讨论选择的过程。 [场景与操作验收](../../Test/course_cli.py)
