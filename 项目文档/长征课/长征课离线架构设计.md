# 长征课离线架构设计

2026 年 11 月 26 日，甲方取消五点式安全带实训课。当前参赛范围仅保留长征课《从于都到遵义》。本文包含长征课的接入定稿和前期两课架构草图。长征课 `main` 使用单屏，双屏设计保存在 [原版归档分支](https://github.com/glyahh/VR-Teaching/tree/codex/teacher-prep-archive)。长征课围绕现场观察和史料查证组织。

长征课的各段设计和验收以[冻结版最高执行标准](长征沉浸式VR党课落地方案.md#冻结版最高执行标准)为准。下面的架构用于复用已有课件、场景和镜头。

长征课的精修桌景已接入正式四站课件。桌景操作和离场恢复见[实景授课说明](../../展示材料/遵义会议室精修场景/场景与素材.md)。

## 长征课架构定稿

《从于都到遵义》以现有四站单文件 HTML 作为正式授课入口。三维探索按需挂在对应课页内，退出后回到原课页。接入后，正式课件和独立样课共用场景代码、模型和动画。课堂操作、史料阅读和返回都在页面内完成，独立样课继续用于练习和验收。课页顺序沿用现有时长资料。 [冻结版最高执行标准](长征沉浸式VR党课落地方案.md#冻结版最高执行标准)

### 课堂上的入口

| 课页 | 展示和操作 |
| --- | --- |
| 于都浮桥近景 | 岸边备桥短片按需点播，片尾接浮桥课页。点「于都河岸」连播铺门板、看桥下、到桥头、夜渡和撤桥，旁白与字幕随镜头切换。横屏沿用片头的整页画面，文字放在上下边缘；窄窗保持完整画幅。播放开始即显示「进入河岸」，点击后暂停短片并在同页打开无人物河岸。返回后保留原播放位置。 |
| 湘江渡口、黎平、猴场、乌江 | 湘江渡口短片呈现渡江及掩护处境，启示页以回望两岸和课内讲述展现牺牲、担当与后续反思。兵力数值在按需查证时显示。猴场点选桌图标出路线，乌江切换岸边的远近机位和带地点的三维地形。五段跨站过渡均以立体地形描线推进。 |
| 遵义会前与会议桌 | 从「遵义会议室」进入精修材料厅，支持点选远处圆点自动漫步前往或 WASD 步行查证行军图与多页手记，离场后把全部已查线索带入「会议桌上的两份材料」。会议桌默认直接可手动翻页、解绳、揭封、拖页与叠图，悬停高亮即时回应。 |
| 课堂回顾与全景总结 | 地形视觉总览保留四站现场回看，片尾用已内嵌的于都、湘江、黎平、遵义画面及地形路线收束。片尾时钟共管镜头、描线和配乐，支持暂停、原位续播、重播和一键返回地图。 |

### 调用方式和模块职责

活动入口在 `content.ts` 的课页表声明，由课页表派生入口映射。教师控制课节，学员可在主控端走动、查证、换角度。正式课件与独立样课使用同一套场景接口。

```ts
const activity = createExploration({ assets })
await activity.open('yudu-river', stage)
activity.close()

const sample = createExploration({ assets, stage: sampleStage })
await sample.open('zunyi-hall')
```

| 模块 | 拥有的状态和职责 |
| --- | --- |
| 授课流程 | `src/content.ts` 定义课页、讲述段落、活动入口与地理数据，`src/lesson-session.ts` 管理单屏课页状态，`src/soundscape.ts` 管理主控端场景音景与交互轻音效，`src/recap-stage.ts` 渲染课尾 3D 图形化总回顾与破晓串联。`src/scene-lesson.ts` 管理单次课页访问的讲述与条目，`src/narration.ts` 按本窗口宽度排版并输出非文字化进度。`src/app.ts` 负责章节、挂载和返回。 |
| 三维场景 | 复用 `walk.js`、`river.js` 和 `viewport.js`。各场景负责自己的机位、物件、材料和演示进度。把操作与样式限定在场景容器内。于都河岸与遵义材料厅在同一窗口共用一个按需创建的 Three.js 渲染器。湘江渡口的预渲染短片与字幕直接打包到课件。 |
| 短片和会议桌 | 开场和各章短片共用 `attachVideo`。`page-entry.ts` 随单次进场管理边缘布局与短句。桌景保存机位、当前书页、封册、散页位置和地图层，`desk-world.js` 由同一份桌面坐标绘制物件与深度。短片按实际画幅校准首尾帧，离页时停播。 |
| 单屏 | 地图、三维活动、材料和回顾共用课件窗口。课页管理本地状态，离开活动时保存已提交的操作结果。 |
| 离线打包 | 两个入口从同一处读取已验收的场景模块和资源清单，用现有 esbuild 方式编译场景代码，再把代码、样式、资源和许可内嵌到各自 HTML。正式构建读取固定清单中的运行文件，缺件时在打包阶段报错。运行文件拷贝到空目录即可打开，Blender 和素材准备留在制作阶段。 |

行军图和手记由材料厅管理，正式河岸短片由浮桥课页控制。课页通过活动 ID 挂载场景，各场景在当前窗口管理机位和已经展示的内容。材料厅记录路线、书页及其可见开合状态、行走界面显隐。正式河岸记录观察的构件、已打开的史料与回看时点，独立样课保留分段三维演示。

正式授课由 `scene-lesson.ts` 维护条目、讲述与已看依据，`story-scenes.ts` 负责课页选择与画面反馈。桌景仍用独立实时渲染器，会议室空闲时准备世界，点击接管同一个在途任务，按目标宽高完成首帧后短淡入。近读和实时纸页共用正反面布局。两条桌景入口共用同一挂载和状态恢复逻辑。

```ts
type ExplorationId = 'yudu-river' | 'zunyi-hall'
type ExplorationView =
  | { id: 'yudu-river', state: RiverView }

  | { id: 'zunyi-hall', state: HallView }

type ExplorationActivity = {
  open(id: ExplorationId, container?: HTMLElement): Promise<boolean>
  apply(container: HTMLElement, view: ExplorationView | null): Promise<boolean>
  read(): ExplorationView | null
  close(): void
  dispose(): void
}

declare function createExploration(options: {
  assets: Readonly<Record<string, string>>
  stage?: HTMLElement
  projection?: boolean
  onChange?: (immediate: boolean) => void
}): ExplorationActivity
```

正式课件用同一入口处理进场、返回和翻页。进入活动时暂停原页媒体，等场景就绪后再切画面。离场时由活动模块暂停、清空按键和指针捕获，停用渲染和事件，同时保存本课内的机位、内容和进度。重进恢复到原位，由教师决定何时继续。方向键由正在操作的场景先处理，普通课页负责翻页。进入新活动或离页时作废旧加载请求。卸载场景宿主时停止帧循环，释放观察器、控制器和显存资源。WebGL 或素材初始化失败时，原课页的图像和短片可继续使用。

正式课件在当前窗口内按课页处理讲述、暂停、进场和回看。双屏会话和投影重连保存在原版归档分支。 [正式课页](../../课堂演示/src/app.ts) · [样课控制](../../课堂演示/自由探索实验/main.js)

会议桌的 `DeskSaved` 保存已提交的机位、页码、封册和落位状态。当前拖动通过单个 `DeskGesture` 预览，松手后回落或提交，离场把已提交状态还给本课。开场影片保留独立播放时钟。`Test/course_cli.py run desk` 实走抽出、叠图、重入和落位恢复。

### 方案取舍

四份草图按授课连续性、状态归属、复用、离线运行和验收比较，交叉评审也选课页内按需挂载。四站课表、桌景和影片继续从现有入口调用，场景接口负责进出与恢复。正式版在单个窗口内运行。

| 比较的方案 | 采用的做法与代价 |
| --- | --- |
| 内嵌独立样课 | 采用把输入和样式限定在场景容器内的做法。完整嵌入独立文档会多一层焦点、状态传递和离线加载。 |
| 全课迁入三维舞台 | 采用课页统一声明活动入口的做法。全面迁移还需要移植并复测地图、既有视频和会议桌。 |
| 主控绘制后向投影发画面 | 把投影分辨率、双窗显存和主控窗口失焦列入实测。连续转发画面需要额外的帧传递和重连机制，按公开状态同步可复用现有配对。 |

### 实施与验收

正式课件的「浮桥近景」和「遵义会议室」分别打开于都河岸和遵义材料厅。`exploration-page.ts` 负责课页进出，`exploration-stage.js` 为正式课件和独立样课提供同一个场景宿主。一个窗口复用一张三维画布。两个入口从同一清单打包运行素材。 [打开正式课件](../../课堂演示/从于都到遵义-课堂演示.html)

验收时将单文件复制到空目录，用 Edge 断网检查河岸演示、原位续播和回看，并检查材料厅线索带入会议桌。教室试讲时检查加载、帧率和后排可读性。 [单屏验收](../../Test/course_cli.py) · [样课验收](../../Test/verify-exploration-prototypes.py)

## 从课堂操作倒推接口

以下为前期两门课的接口草图。长征课的实际接入以[架构定稿](#长征课架构定稿)为准。安全带课取消前的后续设计见[五点式安全带课架构与技术选型](../归档/五点式安全带/五点式安全带课架构与技术选型.md)。

| 调用方 | 一次操作 | 系统负责完成 |
| --- | --- | --- |
| 长征课主屏 | 从侧面绕看会场，点桌上的物件 | 找到对应镜头，从当前观察角度平滑回到约定机位，首帧就绪后切入视频。教师暂停时双屏停在同一处，续播从该处开始。 |
| 安全带二维练习 | 拖部件到人物身上，放错后重试 | 按当前步骤判断目标。错放时保留原状态，弹出一句纠正语；改对后人物和带体原位变化。全程鼠标或触屏操作。 |
| 安全带真人练习 | 学员在地面边穿边讲，结束本项讲解 | 把本轮可见的穿戴表现和口述证据分别对照检查卡。只针对有依据的错误或漏项提示一次，并允许重做。 |

以下为拟议的调用方式，名称供实现时对照。

```ts
march.selectObject("遵义会场/桌上卷宗")
march.pause()
march.resume()

belt.place("胸前连接件", "腿部观察区")
belt.finishExplanation(attemptId)

projection.publish(course.publicView())
```

调用者只表达教学意图。解码是否完成、收到哪个模型回调、投影中途关闭等细节，由相应模块处理。

## 模块边界

| 拟建模块 | 拥有的数据与职责 | 主要接口 |
| --- | --- | --- |
| 离线构建 | 两份入口各自引用的代码、图片、模型、短片与来源，生成独立 HTML。依赖随对应课件交付。 | `pack(entry, assets) → html` |
| 双屏连接 | 配对窗口、会话号和状态版本。课堂操作端是唯一写入者；投影仅渲染，必要时回报就绪。 | 发送公开快照，接收最新版本，重新连接 |
| 长征场景 | 三维地形与会场、物件编号、可选动作、史料及分支。分支改变观察位置、人物回应或接触到的证据，史实由课程内容固定。 | `selectObject(id)`、`choose(action)`、`publicView()` |
| 长征镜头 | 机位、实时场景与影像交接、播放位置。镜头加载或缓冲失败，仍能留在场景讲解。 | `enterShot(id)`、`pause()`、`resume()` |
| 安全带练习 | 经审定的检查卡、二维人物与部件位置、当前步骤、重试记录、一句纠正语。同时拥有真人练习的判读规则。 | `place(part, target)`、`assess(item, evidence)`、`publicView()` |
| 教师端实操观察 | 经授权取得本机摄像头、麦克风，按本轮检查项产生可观察的外观和口述证据。切换学员、退出实操或设备断开时结束该轮采集。 | `startAttempt(item)`、`finishExplanation(id)`、`endAttempt(id)` |

### 长征课的镜头契约

三种入场方式已经用同一套新桌景做成[可离线操作的对照原型](../../展示材料/遵义镜头路线对比/实测与路线选择.md)。该实验覆盖旋转选物、预渲染与实时翻页、首帧交接；正式场景仍需对照选定的原演示截图验收。

三维地形或会场占主屏，地点和物件在场内点选，时间轴与播放控制靠边。先选定一张原演示截图，标出桌沿、窗框等固定参照物。制作端用同一套三维场景导出运行所需的几何与机位，依照原图校准后再出视频。若现有资产只能支持固定画面，先补这个场景的可观察几何。建议固定教学画幅，在不同投影比例下等比留边，使实时图和视频始终采用相同裁切。

```ts
type Pose = { eye: Vec3; target: Vec3; up: Vec3; verticalFov: number }
type Shot = {
  id: ShotId; scene: SceneId; clip: AssetId; approvedStill: AssetId
  entry: Pose; exit: Pose; nextScene: SceneId; aspect: number
}
type MarchView =
  | { kind: "explore"; scene: SceneId; pose: Pose }
  | { kind: "align"; shot: ShotId; pose: Pose; status: "moving" | "held"; run: number }
  | { kind: "film"; shot: ShotId; seconds: number; playing: boolean }
type MarchPublic = { view: MarchView; openMaterials: readonly MaterialId[] }
```

同一镜头清单供制作、播放器和验收使用，记录坐标系、机位换算、光照及道具版本。原图是视觉基准，视频解码首帧是实测对象。入片时同时平滑归位、预解码；两个条件均满足后才交出画面。已连接的投影也在本地首帧就绪后切换；迟到时保持对齐画面，按教师最新播放位置追上。离场按片尾机位接回三维场景。换场、取消或暂停使旧操作编号失效，旧解码回调无法重启播放。若归位中暂停，先保留当前画面，续讲时再完成归位。

### 安全带课的证据契约

检查卡绑定型号、版本、步骤、允许操作、需观察的部位、必讲要点及对应纠正语。二维输入与真人证据沿用同一套术语，分别记入两种练习。二维配对正确只说明该步互动完成。真人观察需要同型号设备、经审核的标注样例及独立实测。

```ts
type Evidence<T> =
  | { kind: "observed"; value: T }
  | { kind: "unclear"; reason: string }
type AttemptEvidence = {
  attempt: AttemptId; item: ItemId
  visual: Evidence<VisibleFinding>
  speech: { kind: "speaking" } | { kind: "finished"; result: Evidence<SpokenFinding> }
}
type Feedback =
  | { kind: "collecting" }
  | { kind: "retry"; instruction: string }
  | { kind: "showAgain"; instruction: string }
  | { kind: "teacherCheck"; item: ItemId }
  | { kind: "continue" }
declare function assess(item: CheckItem, evidence: AttemptEvidence): Feedback
```

例如，确认漏讲时弹“请补充这一处的检查方法”，部位被挡住时弹“请换个角度展示这个部位”。口述结束后才判漏项；听不清时请重说。一次只展示当前最需要处理的一句。异步结果绑定练习轮次、检查项和通道序号，换人后的旧结果丢弃。扣合内部啮合、实际松紧等触检事项交由教师复核。

前半段只加载二维互动，无需设备授权。后半段的视觉与语音识别走本机适配接口，模型须随文件内嵌并在目标电脑断网验证。没有经验证的型号、设备或模型时，仍可运行二维教学和明确标记的示例，真人项目保留为教师判读。课堂默认只留本轮选择、错误及纠正经过，供教师复盘。

### 两个窗口如何保持一致

每份公开快照包含会话号、递增版本和本课的公开画面。长征包含实际机位或镜头、播放位置和已揭示材料；安全带包含步骤、示意状态和教师已揭示的反馈。讲稿、未揭示答案及原始采集音视频留在操作端。控件点击只写一次教学状态，投影取得新快照后直接渲染；重复、过期和其他窗口的消息丢弃。重连取最后一份完整快照。播放中的时间由教师端定期校正，暂停精确恢复到指定位置。投影关闭时教师仍可单屏授课，音频始终只由一个窗口输出。

### 决策怎样影响学习

历史事件、人物回应和可引用的材料随课件预审。一次场内选择可以改变下一镜头、人物展示的物件或要查的史料。教师端按先后次序记录“选择、当时可见的证据、补证后的解释”。安全带课则记录“尝试、证据是否充分、纠正、重做结果”。AI 可以基于本地证据建议一项补充观察，教师决定何时公开。安全带模型的输出先交给检查卡解释，长征中的史实由已审核的分支约束。首个原型先验证选择确实改变画面和任务，后续再评价学习效果。

## 四份草图的取舍

前期两课设计按项目配置并行比较过四份草图。各路均继承同一模型，差异来自独立设计角度。只读评审按离线兼容、首帧可验、实训纠错、双屏重连和接口可测性五项比较，推荐 C 作基底。

| 候选 | 采用的部分 | 取舍理由 |
| --- | --- | --- |
| A 两个独立应用 | 独立入口、资源清单和同型号实物盲测 | 课程可各自交付。先保留旧课件构建入口，避免为了两个新原型改造全部打包流程。 |
| B 共用教学流程图 | 用表描述安全带步骤，错拖时可独立断言步骤和带体状态 | 全局流程图会让视频解码、实物证据等异步条件进入两课共同接口。先让每门课维护自己的分支。 |
| C 教师单写、投影读快照 | **作为基底。** 教师端处理意图，异步返回有轮次和操作编号；投影重连可一次恢复完整公开画面。 | 代价是相机移动时需合并高频更新。只发送最新位姿，并在停手、暂停、切场时发送确定状态。 |
| D 制作资产约束运行时 | 一份镜头清单约束几何、机位和首末帧；一份检查卡约束虚拟练习和可识别项 | 便于验收制作与开发之间的接口。设备生命周期、乱序和暂停恢复仍交给运行时处理。 |

## 实施和验收顺序

以下为前期草图的实施安排。当前长征课按[架构定稿](#长征课架构定稿)实施和验收。

| 次序 | 可单独验证的交付 | 通过条件 |
| --- | --- | --- |
| 1A 长征：一处会场、一件物体、一段短片 | 建立首个真实三维场景、入片机位及参考图，打通自由观察到播放。 | 从两个不同角度点同一物体。按实际投影画幅叠看原图、归位后的实时画面与解码首帧，桌沿和窗框无可见跳位；正常速度无黑帧。缓冲中切场，旧片不抢回来。 |
| 1B 安全带：一个二维动作 | 一项带前置条件的点选或拖动、一个错例、一次重试。可与 1A 同时做。 | 首次体验者拖错后能看懂一句提示并改对；人物及带体在原位更新，全程零摄录权限。 |
| 2 长征：扩成黎平到遵义约 90 秒 | 复用通过验收的镜头交接，加入一次有实际区别的选择、暂停及回看。 | 两份 HTML 分别复制到空目录，在断网 Edge 测试。长征在播放、暂停和展开材料时分别重连，核对机位、时间和物件可见性。重连恰逢翻页时只前进一次，讲稿只在教师端可见。 |
| 3 安全带：同型号一处外观及一句口述 | 取得实物、检查卡和独立样本后接入本地模型。 | 对照教师先行判读，分测可辨错误、确认漏讲、遮挡、听不清、手持教具及换人后的迟到结果。误认或误纠正时退回人工复核。 |

现场讲师、同型号教具仍待落实。它们分别影响现场演示方式和实物验证，第一步的三维转场与二维纠错都可以先行。
