# 室内与河岸交互样课

用启用了 WebGL 2 的 Edge 打开离线样课，用顶部导航切换场景。 [室内与河岸交互原型](./室内与河岸-交互原型.html)

| 场景 | 适用范围 | 操作与反馈 |
| --- | --- | --- |
| 遵义材料厅 · 第一人称 | 室内、院落等中等尺度，需要近看物件和步行查证 | 用 WASD 或方向键移动。按住移动键时收起界面，停下后渐显。走近物件按 E。拨动行军图对照两条路线，点图上地点查证。手记可拖动前后翻四页，每页有一份可打开的页内材料。 |
| 于都河岸 · 分段演示 | 河岸等大空间，需要同时观察多个地点、通行与地形关系 | 点画面或当前按钮，自动播放一段。到观察点停住，教师讲完再点下一段。可环绕、平移、缩放。 |

## 于都河岸分镜

| 操作 | 时长 | 入场、动作与停留 |
| --- | ---: | --- |
| 到桥头 | 3.65 秒 | 由全景降到东门队列侧后方，看到队伍候渡和分批过桥。同一画面留住桥头和窄桥。 |
| 看桥下 | 3.1 秒 | 移到下游桥侧，船向断口驶来，停在尚未接上承托的位置。 |
| 看架桥 | 3.95 秒 | 船工在近处撑篙，两人同时俯身抬板。船靠稳后，门板落到纵梁上，两人松手。停在可指认铰链孔的位置。此时可打开财物赔偿史料。 |
| 看夜渡 | 3.6 秒 | 回全景，天色入夜，两处渡口分别放行。停在两处仍有队伍过河的时点。 |
| 看收桥 | 3.9 秒 | 末队走完，拂晓前桥板回岸，也有拆下的板材随船靠岸。保留全景机位。 |

演示约 18 秒，教师逐段启动，任何一段都可暂停、续播和换角度。「看桥下」和「看架桥」结束后可以看构件。选船体、纵梁、木板或门板时会切到相应机位，看纵梁时揭开部分桥板。退出回到原停留点。最后打开「史料」，选择「夜渡」或「收桥后」，面板随即收起，两种状态共用原机位。行动计划、财物赔偿和两处通行的对照都在课件内阅读。

美术验收先看两处渡口的全景，核对河湾、浅滩和树群的衔接。镜头靠近时检查船肋、纵梁、绳扎、铺板的结构和接触。材料厅进门和看行军图时检查木窗、门槛、展架及错缝地板，按原动线通过。

底部主提示框用深色细磨砂和一圈平面细边。底板复用已有的粗糙度贴图，背景明暗能透进来。行军图与手记补充黎平改向和遵义会前的处境。于都在夜渡与收桥的停留点交代时间压力和隐蔽需要，船与门板材料可在架桥后打开。 [ambientCG Paper 001](https://ambientcg.com/view?id=Paper001)

### 近看物件

遵义材料厅在靠近手记后将镜头推近。可翻的青灰书衣有贴签、固定书脊和四眼穿线。书芯采用 48 张独立建模的纸叶，带错开的纸边与一张夹页。课件中可前后翻阅会前形势、黎平改向、渡过乌江、遵义会前四页。页数和装帧是这件教学复原道具的设计。

于都的近景使用成人比例的人体网格和骨骼。门板、竹篙、桥面和船头踏板各有对应的接触位置。两人抬板、船工撑篙、门板落梁和松手用同一段的时间推进。队伍用同一人体基础烘焙的轻量姿态。

| 动作 | 画面衔接 | 回到原处时 |
| --- | --- | --- |
| 切换两个场景 | 选中标记移到目标标签，前后画面短暂交叠 | 保留室内的视角和取证状态。正在播放的河岸会暂停，返回时可从原处继续。 |
| 展开或收起材料 | 材料在右侧展开，收起后焦点回到入口 | 手记、行军图和分段流程保留当前状态。 |
| 开始一段、暂停和继续 | 主按钮轻压回应，段落位置和状态同时更新 | 段落顺序由教师推进，播放中可随时暂停。 |

交互参考保留操作上下文、让动效说明状态的设计原则。 [Apple 设计原则](https://developer.apple.com/design/human-interface-guidelines/design-principles) · [Apple 动效指南](https://developer.apple.com/design/human-interface-guidelines/motion)

场景借两处渡口做等时对照，布局和通行能力都是课堂设定。正式课件在「浮桥近景」打开于都河岸，在「遵义会议室」打开遵义材料厅。两处都在本页操作，单屏验收见课堂脚本。 [打开正式课件](../../课堂演示/从于都到遵义-课堂演示.html) · [单屏验收](../../Test/course_cli.py)

## 史料和素材

- 于都夜渡面板依据馆藏计划说明时段和渡口安排，采用渡口检查时的赔偿举例说明船主的误工。收桥时的提示依据夜渡与保密史料，说明拂晓前拆桥和清理行军痕迹的目的。 [渡河计划与群众纪律记录](https://v.ccdi.gov.cn/2026/07/22/VIDEJd2Jm6K7XJ7LQ2EsttwF260722.shtml) · [国防部于都探访](https://www.mod.gov.cn/gfbw/gfjy_index/zyhd/4881631.html) · [国家保密局保密史料](https://www.gjbmj.gov.cn/n1/2019/1011/c430154-31394567.html)

- 1934 年 10 月，中央红军出发时从八处渡口过于都河，其中五处架设浮桥。沿岸群众送出民船、门板和木料。通过组数和等候组数用于比较课件内的方案。 [于都县人民政府史料](https://www.yudu.gov.cn/yudu/ydrw/202102/3f856d547c974b18afb023350581f9b0.shtml) · [中国共产党新闻网史料](https://cpc.people.com.cn/n1/2024/1011/c443712-40336727.html)
- 船体和桥板使用旧木扫描材质，船舷、承托与竹篙参考于都馆藏记录。人物以 MPFB 2.0.18 的 CC0 网格与游戏骨架制作，使用粗麻面的法线和粗糙度。 [于都博物馆馆藏](https://www.ydczcfmuseum.cn/article/1005) · [浮桥近景参考](../../课堂演示/assets/yudu-bridge.jpg) · [旧木板](https://polyhaven.com/a/brown_planks_03) · [粗麻](https://polyhaven.com/a/rough_linen) · [MPFB 2.0.18](https://github.com/makehumancommunity/mpfb2/releases/tag/v2.0.18) · [人体基础资产许可](https://github.com/makehumancommunity/mpfb2/blob/v2.0.18/LICENSE.ASSETS.md)
- 河岸的树木、草丛、苔石采用 Poly Haven CC0 模型。近树保留小枝和更多叶片，远树采用简化网格。同类网格共用材质，岸边泥地和渡口小路使用扫描纹理。准备阶段按发布方校验值核对下载内容。 [树木](https://polyhaven.com/a/island_tree_02) · [草丛](https://polyhaven.com/a/grass_medium_01) · [苔石](https://polyhaven.com/a/rock_moss_set_01) · [地表](https://polyhaven.com/a/aerial_grass_rock) · [泥地](https://polyhaven.com/a/dirt) · [CC0 许可](https://polyhaven.com/license)

## 复跑

从仓库根目录执行。准备素材使用 Python、Pillow、NumPy 和已有 Blender 工程。初次准备时联网下载模型、贴图并安装依赖。可传入 `--blender` 指定程序路径，或用 `--nature-only` 单独重建植被、苔石和波纹纹理。验收使用本机 Edge、Python Playwright 和 Pillow。

已有基础贴图和植被缓存时，运行 `python -B "课堂演示/media-source/exploration/prepare_assets.py" --refined-only` 可重建桌边、手记、厅院网格、木船和人物。MPFB 安装在任务内的 Blender 配置目录。可编辑的四份 Blender 工程位于 `.march-build/roam-prototypes/model-refine/可编辑模型/`，工程内打包材质。来源记录与校验值保存在各素材缓存目录，包含 Poly Haven 发布方的 MD5 以及 MPFB 和 Paper001 下载源包的 SHA-256。

运行素材在 `课堂演示/assets/yudu-river/` 和 `课堂演示/assets/zunyi-hall/`。将「于都木船」「于都人物」「于都队伍」分别命名为 `river-boat.glb`、`river-people.glb`、`river-crowd.glb`。遵义将「遵义材料厅」「线装手记」分别命名为 `hall-model.glb`、`folio.glb`，木材与灰泥的颜色贴图命名为 `wood.jpg`、`plaster.jpg`。其余文件沿用清单中的名称。正式课件和样课共用这套素材。 [探索场景打包清单](../../课堂演示/自由探索实验/exploration-assets.mjs)

```powershell
npm --prefix "课堂演示/自由探索实验" ci
python -B "课堂演示/media-source/exploration/prepare_assets.py"
npm --prefix "课堂演示/自由探索实验" run build
python -B "Test/verify-exploration-prototypes.py"
```

脚本把新 HTML 复制到空目录，断网后检查两个场景的实际操作、页内材料和无外站跳转。提示集中在中下方的主操作条。截图存到本地 `.march-build/roam-prototypes/qa/`。

验收脚本逐段核对五次停留、暂停后的画面与进度、同机位回看、重播、史料和遵义操作，在 1920 × 1080、1366 × 768 和 412 px 窄窗下检查面板和按钮。试讲时请学员指着场景说明撤桥的缘由，以及乡亲和部队各做了什么。

同页切场保留河岸机位与播放进度、材料厅的手记状态，关闭材料后恢复焦点。两场景共用一个渲染器。开启「减少动态效果」时直接切换到目标画面。

## 精修验收

- [遵义同机位对照](精修对照/A-遵义建模对照.png)包含庭院、展架、手记三个位置。课堂实际打开手记时镜头额外推近，便于读封签和卷首。重开 Blender 工程核对了 48 张纸叶及内嵌材质。
- [于都同机位对照](精修对照/B-于都建模对照.png)包含桥侧、抬板和落梁后。以 24 帧每秒检查抬板全段的 96 个姿态。松手前，握点与手部骨骼标记的最大偏差约 3 毫米。另核对了立足高度和船舱的可见表面。
- 将 HTML 单独放进空目录，Edge 断网验收两场景。新版五段实测分别为 3.67、3.11、3.95、3.61、3.92 秒。
- 同机运行 Edge 157、Intel Arc，1366 × 768，无界面模式。旧版和新版各交替跑五次，每次都进入河岸并完整播放抬板段。浏览器帧回调间隔的中位数均为 8.3 毫秒，95 百分位的轮次范围分别为 8.4–8.4、8.4–8.5 毫秒。这组数据描述采样时的回调节拍。河岸加载至可操作的中位数由 1.05 秒到 1.22 秒，五轮范围分别为 0.86–1.63 秒和 1.04–1.70 秒。单文件大小由 19.98 MB 到 27.53 MB。
