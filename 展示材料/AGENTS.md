# 展示与交付材料

- PowerPoint 放在 `演示文稿/`，Word 展示报告放在 `报告/`，成果网页、课堂预览和交付压缩包放在 `成果展示/`。
- 长征课介绍片的分镜和实录放在 [12 月介绍视频](12月介绍视频/分镜与素材.md)。场景试作、可编辑工程和验收对照按专题目录保存。
- 课件正式 HTML 和运行素材在 [课堂演示](../课堂演示/AGENTS.md)。成果预览由课件构建生成，更新时从源码重建。
- 用 `python -B "展示材料/成果展示/build-zip.py"` 将当前 `成果与计划.html` 和同次构建的 `课堂预览.html` 一起打入 ZIP。解压到空目录，断网打开成果页和课堂入口。预览 HTML 随 ZIP 放到 GitHub Release，发布前后按[发布离线成品](../AGENTS.md#发布离线成品)核对。
- 交付前把待交文件复制到空目录，实际核对演示文稿的导航、内嵌媒体和文档版式。
