## 实景授课

### 早期桌边镜头参考

[查看手动掀页和双册取证的实际操作动图](./动手查证预览.webp)。

右册的[试拍制作单与参考帧](./右册试拍/制作单.md)附有 6 秒的双人对读分镜。翻页后镜头随笔尖移到右册绳结，供教师接入“会议讨论”材料。正式课件当前可直接点开右册。

| 教学目的与画面焦点 | 机位、动作与选择 | 停顿、衔接与材料性质 |
| --- | --- | --- |
| 找会前改变方向的依据，两册同框 | 教师开启“动手查证”，学员点选卷宗。先选右册可读到会议议题，系统记下这条证据，并提示还需查会前的处境。 | 等学员选择；自由观察机位保持。 |
| 看清手记翻开后得到的证据 | 查证时点左册即到阅读机位。向左或向上拖动手记逐步掀页，反向拖可合上，松手即停。 | 手记用已制作的开合姿态。翻开后显示行军方向的教学摘要。 |
| 核对会议议题 | 左册先读时，点右册完成对读；右册先读时，掀开左册并松手即完成。 | 两份教学摘要在对应卷宗处展开。留在桌边讨论，或结束后换一路重试。 |

用 Edge 打开[正式长征课件](../../课堂演示/从于都到遵义-课堂演示.html)，在首页点“遵义实景”。按原有课序授课时，也可在“遵义会议室”页直接点会议桌入场。课件可单文件复制、断网使用。

桌边支持手动转动、俯仰和拉近。材料页、地图直达和教师单讲共用同一个观察区。

- **绕桌选物。** 拖动空处看桌边，滚轮拉近。两册有快捷阅读入口，内容为教学摘要。
- **动手查证。** 左册从书角正反向翻看四页，短拖松手回落。右册可解绳、掀封、把会议讨论纸页抽出放在桌上。拿已放下的纸页近看后可以放回。摊开行军图，叠看或揭开同一地点的两条路线。
- **现场投影。** 点「双屏授课」，把投影窗移到扩展屏。拖动在投影显示预览。重连和离场回看恢复已落位的纸张、机位、书页和图层。设备回退到正面静图时仍可点选材料。

[可编辑的翻阅工程](./会前的桌边-翻阅动画.blend)保存原模型和贴图，可在 Blender 里核对封面变形。原导览的[镜头与旁白时序](../../课堂演示/media-source/desk-live/guide-notes.md)用于制作新版开场。

这是同一间会议室、同一张桌子的两个机位。场景参考项目已有的遵义会议桌画面，供教学情境审看。纸张上的字样是道具设计。

用 Blender 4.5 打开工程，默认机位是“机位一 · 桌边全景”。煤油灯、茶碗、各层纸张、麻绳和家具均可独立编辑。侧机位可检查封面折角、露出的散页、绳结和薄壁灯罩。两张图均用工程内的 Cycles 设置渲染。后续衔接视频时，可以在选定的机位复制镜头，保留位置、焦距、光照、画幅和曝光，以这一机位重新渲染的静帧核对视频首帧。

### 扩展场景可复用的来源

- 遵义会议会址的修缮实拍可用于核对主楼轮廓、入口与门窗位置。照片反映修缮后的现状，复原历史场景时结合对应年代的史料校对。[新华社会址实拍](https://www1.xinhuanet.com/culture/20260929/1aaf32542ec54a379dd5f5ec4ffdff08/c.html)
- 院落和外墙的灰砖候选是 Amal Kumar 的 Brick Wall 08。颜色、法线和粗糙度的 1K 贴图已下载，并按发布方的校验值核对。缓存位于 `.march-build/source-review/brick-wall-08/`，同目录 `source.json` 记录原始下载地址。使用时按会址参考校对砖块尺寸和色调。[贴图原页](https://polyhaven.com/a/brick_wall_08) · [CC0 许可](https://polyhaven.com/license)
- 行走与碰撞可参考 `three-mesh-bvh` 的现成示例。本地缓存 `.march-build/source-review/three-mesh-bvh-v0.9.18/` 包含上游示例源码、包版本和 MIT 许可证。示例使用 Three.js，适配时用真实场景试走门口和桌边。[固定版本源码](https://github.com/gkjohnson/three-mesh-bvh/blob/1d92383233482f12512ef0804748de45ad7f2f60/example/characterMovement.js) · [许可证](https://github.com/gkjohnson/three-mesh-bvh/blob/1d92383233482f12512ef0804748de45ad7f2f60/LICENSE)

## 复建

从仓库根目录运行。开发机需要 Python、Pillow、NumPy、Windows 楷体和 Blender 4.5。首次准备材料需要联网，已有材料按发布方校验值复用。

```powershell
$work = '.march-build/refined-table/materials'
$out = '展示材料/遵义会议室精修场景'
$blender = '.march-build/blender-4.5.4-windows-x64/blender.exe'
python -B '课堂演示/media-source/desk-study/prepare.py' $work
& $blender -b --factory-startup --python-exit-code 1 -P '课堂演示/media-source/desk-study/build_scene.py' -- --work $work --out $out --model-only
python -B 'Test/verify-desk-study.py' --blender $blender --model "$out/会前的桌边.blend" --render-to $out
```

最后一步把工程单独复制到临时空目录，检查内嵌图像和两台机位，再从重新打开的工程输出两张 1920 × 1080 图片。

本次交付已按此流程实测，工程内含 15 张图像，外链 Blender 库数量为 0。

复建课堂镜头时，先完成上面的静态工程和主视图。从仓库根目录执行以下命令，空间导出、翻页和导览中间文件均在本地构建目录中。

```powershell
$blender = '.march-build/blender-4.5.4-windows-x64/blender.exe'
$scene = '展示材料/遵义会议室精修场景/会前的桌边.blend'
ffmpeg -v error -y -i '展示材料/遵义会议室精修场景/会前的桌边.png' -vf 'scale=1280:720:flags=lanczos' -frames:v 1 -q:v 2 -pix_fmt yuvj444p '课堂演示/assets/desk-front.jpg'
& $blender -b --disable-autoexec $scene --python-exit-code 1 -P '课堂演示/media-source/desk-live/export_space.py' -- --mode all
python -B '课堂演示/media-source/desk-live/render_action.py'
python -B '课堂演示/media-source/desk-live/make_leaf_strip.py'
python -B '课堂演示/media-source/desk-live/make_guide.py' build
node '课堂演示/build.mjs'
python -B 'Test/verify-desk-live.py'
```

正式实时桌景用原精修工程导出干净底图与静态几何，在同一深度缓冲中绘制可动纸件。重新制作底图时，用同一个 Blender 和原工程执行 `-b --disable-autoexec <原工程> --python-exit-code 1 -P "课堂演示/media-source/desk-live/export-live-desk.py" -- --samples 24`。准备好四个 `desk-world` 资源后重建 HTML，执行 `python -B "Test/course_cli.py" run desk` 检查斜侧拖动、落桌、叠图和双屏。仅改查证提示或课页动效时，可直接重建 HTML。旧姿态图集及其命令留作前期镜头复现。
